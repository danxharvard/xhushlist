Questions.

Which list should I use?

Start with the main list. Add others only if you need what they block. Using lists that overlap won't break anything, but it doesn't help either.

A site I need stopped working. What now?

Allowlist the domain in your blocker for a quick fix, then use "Report a domain" so it can be removed from the list for everyone.

How often is the list updated?

Whenever changes are made. Most blockers check for updates on their own, usually once a day or once a week.

Does this cost anything?

No. The list is free to use, with no account needed.

Can I add Hushlist to my Home Screen?

Yes. On iPhone, tap Share then Add to Home Screen. On Android, open the browser menu and tap Add to Home screen.
